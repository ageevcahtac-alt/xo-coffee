# Фото пачек для drawer лота

Одно фото на регион (страну происхождения). Drawer показывает его вверху
паспорта лота; если файла для региона нет — блок целиком не рендерится
(без битых картинок и пустых рамок).

## Именование

`<slug>.png`, где slug — латинский ключ региона из словаря
`src/lib/lotRegions.ts`:

| Регион | Файл | Регион | Файл |
|---|---|---|---|
| Эфиопия | `ethiopia.png` | Перу | `peru.png` |
| Кения | `kenya.png` | Гватемала | `guatemala.png` |
| Колумбия | `colombia.png` | Коста-Рика | `costa-rica.png` |
| Бразилия | `brazil.png` | … | … |

Полный список — `ENTRIES` в `src/lib/lotRegions.ts`. Двойное расширение
(`.png.png`) сервер терпит, но лучше не создавать.

## Требования к файлу

- Формат: PNG или JPG.
- Ориентация: вертикаль или квадрат (в drawer фото вписывается в квадрат
  со стороной 224–256px, `object-contain` — фон картинки остаётся её фоном).
- Вес: желательно ≤ 500 КБ (сейчас лежащие файлы ~2 МБ — сжать при
  возможности).
- Фон и подложка — на усмотрение; рамка сайтом не добавляется.

После добавления файла ничего перезапускать не нужно — манифест читается
с диска на каждый запрос.
