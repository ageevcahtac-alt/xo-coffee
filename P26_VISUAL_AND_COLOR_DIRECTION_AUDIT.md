## 1. Текущая визуальная система

Прочитано построчно: `app/globals.css`, `app/layout.tsx`, `FixedBackdrop.tsx`, `Header.tsx`, `Hero.tsx`, `Approach.tsx`, `Catalog.tsx` (карточка полностью), `Manifest.tsx`, `Footer.tsx`, `WholeBeanNotice.tsx`, `ui/Modal.tsx`, `LotPassportModal.tsx` (весь модал целиком), плюс grep по всему `src/components` на семантические цвета и focus-состояния.

**Структурный паттерн:** каждая секция главной страницы (`Hero`, `Approach`, `Manifest`, `Footer`) — это один и тот же контейнер: `rounded-2xl/3xl`, `border-gold/20`, `backdrop-blur`, плавающий на постоянном полноэкранном тёмном фоне (`FixedBackdrop`, `position: fixed`, z-index -10). Внутри этих тёмных "стеклянных" панелей контент либо остаётся тёмным (текст `cream` на `bg-backdrop/35` или `bg-burgundy-dark`), либо переключается на светлые карточки (`bg-cream/85` — карточки каталога, шаги `Approach`, модальные окна). Это уже зрелая, последовательно применённая система — не хаос, а осознанный, но однобокий выбор (см. раздел 3).

**Типографика:** Playfair Display (serif, `--font-display`) для заголовков/цитат, Manrope (`--font-sans`) для тела и UI. Uppercase + широкий `tracking` (`0.1em`–`0.35em`) — сквозная микро-типографическая конвенция для лейблов/эйбраузов/кнопок/бейджей, применена абсолютно последовательно во всех 10+ просмотренных компонентах.

**Постоянный декоративный слой:** `FixedBackdrop.tsx` рисует на весь экран, за каждой секцией, иллюстрированный узор из кофейных веток, листьев, цветков и зёрен в золотой фольге (`gold-foil` SVG-градиент), поверх тёмного градиента burgundy→backdrop, с постоянной непрозрачностью 0.32. Это не просто "акцент" — это буквально фоновый слой всего сайта, 100% времени просмотра.

**Фотография:** **отсутствует полностью.** `public/` содержит только дефолтные Next.js SVG-заглушки; ни один компонент не рендерит `<img>`/`next/image` продукта, чашки, упаковки или интерьера. Весь визуальный язык сайта сегодня — это цвет + типографика + один иллюстративный узор, без единой реальной фотографии. Это меняет постановку вопроса из брифа "как цвет взаимодействует с фотографией" — сегодня взаимодействовать физически не с чем (раздел 11).

## 2. Текущая цветовая палитра (с HEX)

Источник — `app/globals.css` (единственное место, где определены именованные токены) плюс built-in-значения, встречающиеся только инлайново.

| Токен/использование | HEX | Где встречается |
|---|---|---|
| `--color-burgundy` | `#3b1119` | Основной тёмный акцент: CTA "В корзину", тёмные панели-карточки, заголовки на светлых карточках |
| `--color-burgundy-dark` | `#260b10` | Hover-состояние burgundy CTA, карточки Manifest |
| `--color-backdrop` | `#0f080a` | Фон `FixedBackdrop`, хардкод `#0F080A` в `Header` (без токена — расхождение, см. раздел 3) |
| `--color-cream` | `#fbf8f1` | Светлый фон карточек/модалок, основной текст на тёмном |
| `--color-cream-dark` | `#f4efe6` | Вторичные светлые поверхности (теги вкуса, брю-карточки) |
| `--color-gold` | `#d4af37` | Главный акцент: бордеры, лейблы, hover, wordmark, shimmer-анимация активных табов |
| `--color-gold-dark` | `#a9872c` | Текст на золотых плашках, hover для gold CTA |
| `--color-charcoal` | `#222222` | Основной текст тела (`body`), текст на светлых поверхностях |
| *(не токенизирован)* `red-700` | `#b91c1c` (Tailwind default) | **Единственное** место с семантическим цветом — ошибка формы в `CheckoutForm.tsx`, хардкод, не часть системы |
| *(не токенизирован)* gold-foil градиент | `#F3E5AB → #C5A059 → #D4AF37 → #8A6D3B` | Декоративный SVG-паттерн `FixedBackdrop`, только там |

По категориям из задания:

| Категория | Текущее значение |
|---|---|
| Background | Тёмный градиент `backdrop → burgundy → backdrop` + иллюстрированный узор (не плоский цвет) |
| Surface | Два конкурирующих варианта: `bg-backdrop/35` (тёмное стекло) и `bg-cream`/`bg-cream/85` (светлая карточка) |
| Surface secondary | `bg-cream-dark` (светлый контекст) / `bg-burgundy-dark` (тёмный контекст) |
| Primary text | `charcoal` на светлом, `cream` на тёмном |
| Secondary text | `charcoal/50-75` или `burgundy/70-80` на светлом; `cream/70-85` на тёмном |
| Muted text | `charcoal/40-45`, `burgundy/45`, `cream/40-50` |
| Border | **Почти везде `gold/20-40`**, независимо от контекста — единственный системный бордер-цвет сайта |
| Primary accent | `gold` |
| Secondary accent | `burgundy` |
| CTA | **Два разных варианта** (раздел 3) |
| CTA hover | `gold-dark` / `burgundy-dark` — соответствует своему CTA |
| Product badges | `border-gold(/40) + bg-gold/15 + text-gold-dark` (тег "Точка входа") или `border-gold/40 + bg-cream + text-burgundy` (Q-score, "Паспорт") |
| Informational elements | `border-l-2 border-gold + bg-burgundy/[0.04]` (`WholeBeanNotice`) |
| Success/Error/Warning | **Не определены.** Единственное исключение — один хардкод `text-red-700` |
| Dark sections | Header, Hero, Approach, Manifest, Footer — то есть большинство "полноразмерных" секций сайта |
| Image overlays | Не применимо — фотографий нет (раздел 1) |

## 3. Проблемы текущего дизайна

Зафиксировано только то, что подтверждается конкретным местом в коде, не вкусовые ощущения:

1. **Дисбаланс "светлый интерьер" против фактической тональности сайта.** Бренд-база прямо описывает "светлый современный интерьер... золото как аккуратный премиальный акцент". Фактически: почти каждая полноразмерная секция (`Header`, `Hero`, `Approach`, `Manifest`, `Footer`) — тёмная, золото используется не дозированно, а как основной постоянно видимый акцент (бордеры почти всех элементов, shimmer-анимация на активных табах, доминирующий цвет ховера). Светлыми остаются только внутренние карточки/модалки. Это не "ошибка", а осознанный выбор прошлой фазы ("dark-glass gold-foil theme" — по сообщению коммита), но он прямо противоречит текущей бренд-базе задания.
2. **Постоянный иллюстрированный кофейный узор на 100% экрана.** `FixedBackdrop` — это ровно тот риск, который бриф явно называет ("не превращать сайт в типичную кофейню с кофейными зёрнами на фоне"). Исполнение аккуратное (золотая фольга, не клипарт), но сама идея — литеральные ветки/зёрна/цветки кофе как фон каждой секции — концептуально ближе к "hipster coffee template", чем к "specialty coffee brand".
3. **Две конкурирующие CTA-трактовки.** Hero: `bg-gold` + `text-burgundy` (главная CTA "Смотреть каталог"). Каталог/модалка/повсюду при покупке: `bg-burgundy` + `text-cream` + `border-gold/40` ("В корзину"). У сайта нет одного однозначного "это и есть CTA-цвет" — это может путать восприятие приоритета действия.
4. **`backdrop` захардкожен в двух видах.** Токен `--color-backdrop: #0f080a` существует, но `Header.tsx` использует буквальный `bg-[#0F080A]/75` вместо `bg-backdrop/75` — тот же цвет, но не через систему токенов. Мелкая находка, но показательная: даже внутри уже существующей системы есть расхождения.
5. **Нет семантической системы success/warning/error.** Только один хардкод `text-red-700` в одной форме. Ни одного success-состояния с определённым цветом (страница успеха заказа не проверялась на цвет, но сам факт отсутствия токена — уже находка).
6. **Нет системных focus-состояний.** У текстовых полей — `focus:border-burgundy` (без видимого кольца, `outline-none`). У кнопок, ссылок, кликабельных карточек (`role="button" tabIndex={0}` в `Catalog.tsx`) — **ни одного** явного `focus-visible`-стиля нигде в `src/components` (grep по всему дереву — 0 совпадений, кроме двух форм). Это не сломано (браузер, скорее всего, показывает свой дефолтный контур), но и не спроектировано — на премиальном сайте дефолтный синий контур браузера поверх burgundy/gold палитры будет визуально чужеродным.
7. **Тройная терминологическая перегрузка слова "Паспорт" без визуального различения.** Подтверждено построчно: (а) `LotPassportModal` — "Паспорт зерна", модалка карточки товара, доступна любому до покупки; (б) `CoffeePassportDetail`/`CoffeePassportPage` (`/passport/[orderNumber]`) — личный дегустационный дневник, только после покупки, отдельный компонент с похожей, но не идентичной вёрсткой; (в) будущая внешняя Coffee Passport-платформа (P14/P20/P23). Визуально все три сегодня используют один и тот же язык (тот же gold-бордер бейдж, тот же шрифт, то же слово), хотя это три разных по масштабу и назначению вещи. Не критично сегодня (нет визуального конфликта, потому что внешняя платформа ещё не подключена), но заложенный риск на будущее.
8. **Карточка каталога информационно плотная.** Подтверждено построчным чтением `Catalog.tsx`: на одной карточке — до 9 отдельных текстовых/бейдж-элементов до кнопки покупки (лейбл лота, бейдж "Паспорт", происхождение, регион, Q-score, тег входа/направление вкуса, cup note, "кому понравится", как готовить, специфика лота, "только цельное зерно"). Каждый элемент по отдельности оправдан (видно по комментариям в коде — сознательные решения предыдущих фаз), но суммарно это ближе к "информационной таблице", от которой бриф прямо просит уйти.

## 4. Что обязательно сохранить

Не подлежит уничтожению "просто ради новизны" — подтверждённые сильные стороны:

- **Пара шрифтов Playfair Display + Manrope** — уже читается premium + specialty + спокойно, ровно то, что просит бриф. Менять не за что.
- **Uppercase + tracking микро-типографика** для лейблов/кнопок/эйбраузов — последовательна, работает, не "ресторанное меню".
- **Информационная архитектура карточки лота и модалки** — "Level 1: plain-language summary" → тех.данные → терруар → рецепты → похожие лоты (`LotPassportModal.tsx`, буквально закомментировано в коде как осознанный слоистый дизайн). Это ядро "понятного пути от зерна до чашки" — центральная бренд-опора задания. Убирать нельзя, максимум — визуально облегчить плотность (раздел 3, п.8).
- **Позиционирование Pure Roast уже правильное.** `Approach.tsx`: *"Pure Roast — это то, как мы ищем профиль для каждого лота отдельно, а не единая «правильная» степень обжарки"* — ровно "метод, не отдельный бренд". `Footer.tsx` уже показывает "Pure Roast" мелко, в один ряд с копирайтом, уступая место логотипу XO COFFEE. Ничего менять не нужно, только сохранить как правило (раздел 14).
- **Голос бренда/копирайтинг.** "У каждого зерна — своя точка раскрытия. Мы её находим.", "Мы боремся за вкус.", "Важен первый глоток!" — спокойный, уверенный тон без крика, ровно по брифу. Не переписывать.
- **Origin-forward иерархия карточки** (страна крупнее, чем внутренний код лота) — разумное решение для specialty-бренда, где происхождение продаёт лучше артикула.
- **Паттерн "плавающая светлая карточка на выразительном фоне"** для карточек товара и модалок — работает как приём "товар на подиуме"; стоит сохранить сам приём, даже если фон вокруг изменится (раздел 6).
- **`WholeBeanNotice`** — тон и решение (левый золотой акцент + приглушённый фон) хорошо служит информационным блокам, не будет затронуто выбором направления.

## 5. Что необходимо изменить

Прямо вытекает из раздела 3, без домысливания вкуса:

- Сдвинуть общий баланс светлого/тёмного в пользу светлого — по факту, не только на уровне отдельных карточек.
- Снизить интенсивность/буквальность иллюстрированного кофейного узора на `FixedBackdrop` — либо сильно абстрагировать, либо убрать как постоянный полноэкранный слой.
- Определить **один** основной CTA-цвет вместо двух конкурирующих.
- Ввести цвет-токены для success/warning/error вместо единственного хардкода.
- Определить явное, системное focus-состояние (кольцо/бордер), а не полагаться на дефолт браузера.
- Снизить плотность карточки каталога — определить, какие 9 элементов остаются на карточке, а какие уходят только в модалку (конкретный список — задача следующего этапа реализации, не P26).
- Провести бордер `--color-backdrop` через токен в `Header.tsx` вместо хардкода HEX.

## 6. Три визуальных направления

### Направление A — Warm Premium

**Идея:** реализовать бренд-базу почти буквально. Тёплый светлый нейтральный фон — доминирующая поверхность почти везде. Charcoal/чёрный — основной контрастный цвет (заголовки, бордеры, основная CTA). Burgundy — уменьшается до подписи/акцента бренда (теги, отдельные акцентные слова, связь с упаковкой). Gold — минимален: тонкие линии, мелкие засечки, никакой заливки/сияния. Иллюстрированный узор убирается полностью.

- **Настроение:** бутик, светло, уверенно — ближе к премиальному товару/украшению, чем к "кофейне".
- **Accent:** charcoal как основной, burgundy как единичный акцент, gold — только линия.
- **CTA:** charcoal-заливка, cream-текст.
- **Преимущества:** максимально соответствует формулировке бренд-базы; лучший контраст "из коробки"; лучше всего масштабируется на будущую фотографию (светлый нейтральный фон — самый благодарный для съёмки чашки/упаковки); минимальный риск "кофейного клише".
- **Риски:** самый большой визуальный разрыв с текущим сайтом (наибольшая стоимость реализации из трёх); теряется часть теплоты/насыщенности, которую даёт burgundy+gold сегодня; без реальной фактуры (дерево/стекло, упомянутые в бренд-базе) может читаться суховато/обобщённо, если не добавить материальные детали позже.
- **Соответствие XO COFFEE:** высокое по букве бренд-базы, среднее по преемственности с уже вложенным визуальным капиталом.
- **Сочетание с фотографией:** отличное.
- **Мобильный:** очень хорошо (светлый UI дешевле контролировать по контрасту).
- **Масштабируемость:** высокая.

### Направление B — Refined Burgundy Specialty (РЕКОМЕНДУЕТСЯ)

**Идея:** не менять цветовую семью (burgundy + gold + cream + charcoal уже завязана на упаковку Pure Roast и уже качественно исполнена), но **перебалансировать пропорцию и дисциплину использования**: cream становится доминирующей поверхностью на большинстве секций (не только внутри карточек — сами секции светлеют), тёмный burgundy/backdrop остаётся, но осознанно, для 1–2 акцентных секций (например, "Манифест" — там драматичный тёмный фон работает на смысл текста), иллюстрированный узор `FixedBackdrop` заменяется на сильно упрощённую/абстрактную текстуру или убирается как навязчивый слой, gold перестаёт быть заливкой/сиянием и становится тонкой линией/акцентом (убрать shimmer-анимацию активных табов как приём, который слишком буквально "сияет золотом"), CTA унифицируется в один цвет — burgundy-заливка (более узнаваемый, отличительный выбор, чем "ещё один золотой сайт").

- **Настроение:** уверенное specialty-ремесло с премиальной сдержанностью — теплее и насыщеннее, чем A, спокойнее и светлее, чем текущий сайт.
- **Accent:** burgundy — основной идентификационный акцент; gold — дозированный вторичный.
- **CTA:** единая burgundy-заливка, cream-текст.
- **Преимущества:** сохраняет вложенный капитал бренда (burgundy = реальный цвет упаковки Pure Roast, уже увиденный покупателем); наименьшая реалистичная дистанция от текущей реализации (эволюция, не замена — меньше риска "выбросить то, что уже работает"); напрямую закрывает обе найденные конкретные проблемы (два CTA, дисбаланс тёмного) без изобретения новой палитры с нуля.
- **Риски:** требует дисциплины — burgundy+gold вместе снова могут скатиться в "кофейню", если дозировка не будет строго соблюдена; полностью "раскроется" только с реальной продуктовой фотографией, которой пока нет.
- **Соответствие XO COFFEE:** высокое — прямая связь с реальной упаковкой Pure Roast, сохраняет узнаваемость.
- **Сочетание с фотографией:** хорошее — тёплый cream фон выгодно оттеняет кофе/чашку/зерно, burgundy не спорит с типичными коричневыми тонами обжаренного зерна (в отличие от, например, коричневой палитры, которую бриф явно запрещает).
- **Мобильный:** хорошо — основной риск (читаемость gold-текста на тёмном при низкой яркости экрана) снимается за счёт того, что тёмных поверхностей становится меньше.
- **Масштабируемость:** высокая — палитра уже опробована на 10+ компонентах, задача не "придумать с нуля", а "применить новую пропорцию".

### Направление C — Modern XO

**Идея:** почти монохромная нейтральная система. Тёплый off-white/камень как фон, near-black/charcoal — почти для всего (текст, основная CTA, бордеры). Burgundy — единичный, очень редкий фирменный штрих (например, одна строка, один таг, подчёркивание слова "COFFEE" в логотипе). Gold почти полностью убирается, кроме буквально одного-двух премиальных моментов (эмбосс/фольга на особом бейдже лимитированного лота). Ближе к минималистичному дизайн-ориентированному потребительскому бренду (специализированная электроника/уход), чем к "кофе" как категории.

- **Настроение:** тихая роскошь, редакционность, сдержанность.
- **Accent:** charcoal/near-black — единственный системный, burgundy — точечный.
- **CTA:** near-black заливка, cream-текст.
- **Преимущества:** максимальный контраст/доступность "из коробки"; самая чистая масштабируемость; минимальный риск "hipster coffee template" из всех трёх.
- **Риски:** попадает ровно в другой риск, который бриф тоже прямо запрещает — "luxury fashion clone"; теряет почти весь уже наработанный визуальный капитал (burgundy/gold и всё, что с ними ассоциативно связано с упаковкой); рискует читаться "премиально вообще", а не специфично про specialty-кофе; самая большая потеря уже работающего материала из трёх направлений.
- **Соответствие XO COFFEE:** среднее — эстетически сильное, но обрывает связь с реальным продуктом/упаковкой сильнее, чем нужно.
- **Сочетание с фотографией:** отличное технически, но рискует читаться холодно без сильной фотографии, которой сегодня нет.
- **Мобильный:** отличный.
- **Масштабируемость:** отличная — ценой узнаваемости.

## 10. Typography direction

- Body — Manrope, обычный/medium.

- Product names/coffee names — Playfair.
- Metadata (регион, специи, дата) — Manrope, приглушённый цвет.
- Decorative/script — не вводить (бриф прямо просит не превращать сайт в ресторанное меню; сегодня script-начертаний нет — не нужно и не будет).

## 11. Product card direction

## 14. Pure Roast visual role

Уже в основном правильно (раздел 4). Формализуемые правила для направления B:

- **Размер:** всегда меньше, чем "XO COFFEE" — как сейчас в `Header`/`Footer`/`Hero` (эйбраз "Метод обжарки Pure Roast" — мелкий текст над заголовком, не сам заголовок).
- **Цвет:** нейтральный/приглушённый (`cream/70` или `charcoal/60`), не собственный акцентный цвет — Pure Roast не должен иметь "свой" цвет, отдельный от системы XO COFFEE.
- **Размещение:** либо как эйбраз-лейбл над заголовком (Hero, Approach), либо как мелкая подпись рядом с копирайтом (Footer) — никогда как отдельный "суб-бренд" блок с собственным логотипом-заменителем.

- **Отношение к логотипу XO COFFEE:** Pure Roast никогда не заменяет и не соседствует 1:1 по размеру с "XO COFFEE" — всегда в подчинённой типографической роли (меньше кегль, ниже контраст, отдельная строка).

## 15. Button/UI direction

- **Кнопки:** один основной CTA-цвет (burgundy-заливка, раздел 9) для главных конверсионных действий («В корзину», «Оформить», Hero-CTA); одна вторичная форма — outline (текущий border-cream/charcoal + текст, hover в accent) для некоммитных действий («Не знаю, что выбрать», навигация назад/вперёд).
- **Карточки:** сохранить текущую форму (rounded, border, hover-приподъём) — уже premium-ощущение, не требует изменений формы, только цветового контекста (раздел 9).
- **Бейджи:** различить по назначению визуально, не только по тексту — например, "информационный" бейдж (Q-score, факт) остаётся нейтральным (border+cream), "продающий" бейдж (Точка входа, направление вкуса) остаётся акцентным (gold-dark), а бейдж, ссылающийся на модалку/паспорт, получает третий, самый сдержанный вид (просто текст-иконка, без рамки) — чтобы не спорить визуально с двумя другими.
- **Фильтры/табы:** сохранить текущую механику вкладок, убрать shimmer-анимацию `tab-active-glow` как приём (раздел 3, п.1) — заменить на статичное состояние (заливка/подчёркивание accent-цветом без анимированного "сияния").
- **Навигация (desktop/mobile):** сохранить структуру (`Header.tsx`, `MobileMenu.tsx` не пересматривались построчно в этой сессии, но не задевают палитру — их логика не меняется направлением B).
- **Формы/checkout:** только смена цвет-токенов (border/focus), логика и структура полей не меняются.
- **Модалки:** сохранить cream-базу (`ui/Modal.tsx`) — уже правильный светлый "подиум" для товара на любом фоне страницы.
- **Разделители:** border-по-умолчанию переходит на `charcoal/12` вместо повсеместного `gold` (раздел 9) — gold-разделитель остаётся только там, где он несёт акцентный смысл (например, разделение цены и CTA в футере карточки — по решению реализации).
- **Иконография:** сохранить текущий минимальный line-icon стиль (`stroke="currentColor"`, `strokeWidth="1.5"`) — уже соответствует "спокойно + premium".
- **Hover-состояния:** сохранить принцип (лёгкий подъём/цвет), убрать глобальный shimmer.
- **Focus-состояния:** ввести явное системное focus-кольцо (раздел 9) — сегодня отсутствует как система.

## 16. Responsive principles

Концептуально (без пересборки на устройствах в этой сессии — только структурный анализ существующих классов):

- Структура секций-панелей (`rounded`, `border`, `backdrop-blur`) уже одинаково держится на всех брейкпоинтах — `Hero`/`Approach`/`Manifest`/`Footer` используют responsive-паддинги (`sm:`/`md:`/`lg:`), но не меняют саму композицию — сохранить.
- Каталог уже переключается `grid-cols-1 → md:grid-cols-2 → lg:grid-cols-4` — сохранить, но при сокращении плотности карточки (раздел 11) мобильная карточка выиграет больше всего (меньше прокрутки на маленьком экране до цены/CTA).
- Акцентные цвета (gold, burgundy) на мобильном экране при ярком солнечном свете хуже читаются в мелком тексте, чем на десктопе — довод в пользу того, чтобы (раздел 9) gold использовался только акцентно/крупно, не для мелкого информационного текста.
- CTA на мобильном — уже полноширинные в некоторых местах (`Hero`: `w-full sm:w-auto`) — сохранить паттерн "full-width CTA на мобильном, авто-ширина от sm".
- Header остаётся фиксированным (`fixed top-0`) — при переходе на более светлую общую палитру стоит на этапе реализации перепроверить контраст фиксированного хедера над прокручивающимся светлым контентом (сегодня тёмный хедер поверх тёмного фона не создаёт проблемы контраста; поверх светлого потребуется either сохранить хедер тёмным как "premium anchor bar", either явно перепроверить).

## 17. Accessibility considerations

- **Контраст:** `charcoal` (#222222) на `cream` (#fbf8f1) — контраст ~15.8:1, далеко за пределами AA/AAA для любого размера текста. `cream` на `burgundy` (#3b1119) — контраст ~11.5:1, тоже отличный. Проблемная пара — **`gold` (#d4af37) как текст на тёмном фоне** (например, `text-gold` эйбраузы на `bg-backdrop`): контраст ≈ 8.4:1 к `#0f080a` — приемлемо, но `gold` на более светлом тёмном участке (например, поверх `burgundy` #3b1119) даёт контраст ≈ 3.1:1 — **ниже AA для обычного текста (4.5:1)**, приемлемо только для крупного/жирного текста (используется в основном для крупных эйбраузов/лейблов, что снижает риск, но не устраняет его для более мелких вхождений). Рекомендация направления B — использовать `gold-dark` (#a9872c) вместо светлого `gold` там, где это текст, а не декоративная линия/бордер (раздел 9 уже это фиксирует).
- **Focus states:** зафиксированный пробел (раздел 3, п.6) — закрывается явным токеном (раздел 9).
- **Не жертвовать читаемостью:** предложенные success/warning/error (раздел 9) — все три подобраны в тёплой, не кислотной гамме, но каждый должен пройти отдельную контраст-проверку на своей реальной поверхности (cream) на этапе реализации, до применения в коде — здесь они предложены концептуально, не протестированы автоматическим инструментом.
