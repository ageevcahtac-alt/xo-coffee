## 2026-11-07 — fix/post-purchase-passport-handoff → PR #3

**Что:** (1) Success-экран после заказа стал честным: везде «заказ оформлен»
(эквайринг не подключён — «оплачен» нигде не утверждается), ручная
инструкция по оплате (СБП/счёт: реквизиты отправляем после подтверждения;
карта: честная пометка о тестовом режиме без списания), явные номер заказа,
состав и сумма, существующие контакты поддержки из Footer вместо выдуманных
авто-писем «чек и трек-номер придут». Локальная /passport/[orderNumber]
сохранена и подписана «Состав заказа на этом устройстве» — без обещаний
аккаунта и доступа с других устройств. (2) Новый спокойный блок «Познакомьтесь
с вашим кофе в Coffee Passport» со ссылкой в НАСТОЯЩИЙ паспорт лота через
getCoffeePassportUrl(lot) (тот же единственный проверенный строитель, что в
LotPassportModal; только при passportPublicId — иначе кнопки нет, URL не
угадывается). Ничего не обещает про статусы заказа в Паспорте. (3)
buildOrderMessage больше не падает на минимально валидном payload без
payment/delivery (дефект read-only прогона Этапа 2A: заказ создан,
notified:false) и на нетипизированных полях, которые isValidPayload
пропускает; полный формат сообщения байт-в-байт прежний (golden-тест).

**Почему:** задача владельца «Этап 2A: честный post-purchase UX, переход в
настоящий Coffee Passport, малый дефект Telegram». Sandbox-оплата
(тестовая карта, декоративный QR) намеренно НЕ тронута и зафиксирована
владельцу как NO-GO блокер боевого запуска, а не замаскирована текстом.

**Не тронуто (сознательно):** логика создания заказа, доставка уведомлений,
платёжная логика, Admin, данные, миграции, деплой; синхронизация статусов
заказа с Coffee Passport, клиентские уведомления, эквайринг — вне PR.

**Проверки:** `npm test` 126/126 ✓ · `npm run lint` чисто ✓ · `npm run build` ✓ ·
UI-прогон (puppeteer против mock Admin, десктоп 1440 + мобильный 390):
заказ с passport_public_id (ссылка в блок есть, href =
coffee-passport.onrender.com/passport/<public_id>), заказ без него (блока
нет, мёртвой кнопки нет), ручная оплата СБП, ошибка сети (корзина
сохранена, success нет), на 390px без горизонтального переполнения ✓
(артефакты: .agents/runs/2a-post-purchase/, локально, в git не коммитятся).

**Ревью:** Codex (scripts/codex-run.ps1, MODE: review, песочница read-only),
2 раунда. Раунд 1: findings: none. Раунд 2: 2 findings (medium) — падение
escapeHtml на нетипизированных полях и lookup «constructor» в записях
методов оплаты; оба исправлены в 4c3e38e, регрессионный тест добавлен.
Отчёты: .agents/runs/post-purchase-review/report-1.md, report-2.md.

**Риски:** низкие; откат — revert трёх коммитов (252becc, c78a429, 4c3e38e).
Ссылка в Паспорт строится из env-шаблона NEXT_PUBLIC_COFFEE_PASSPORT_LOT_URL_TEMPLATE
с fallback на публичный деплой паспорта — если шаблон не задан, работает
fallback (поведение единого строителя, покрыто тестами passportIdentity).

**Ссылки:** PR https://github.com/ageevcahtac-alt/xo-coffee/pull/3

## 2026-11-05 — chore/remove-maroon-bg → PR #1

**Что:** остаточные сырые бордовые фоновые классы (`bg-burgundy`,
`bg-burgundy-dark`) в 9 компонентах переведены на семантические токены P27
(`bg-accent`, `bg-accent-hover`). Визуальных изменений нет
(`--color-accent` = `--color-burgundy` #3b1119, `--color-accent-hover` =
`--color-burgundy-dark` #260b10, app/globals.css).

**Почему:** задача владельца «убрать устаревший бордовый фон». Разведка
показала: старый полноэкранный бордовый фон (FixedBackdrop) удалён ещё в
P27; актуальная палитра — P26 направление B «Refined Burgundy Specialty»,
где бордовый — намеренный брендовый акцент (упаковка Pure Roast). Устаревшим
оставался только сырой слой токенов поверх семантического.

**Не тронуто (сознательно):** шапка `bg-backdrop/90` (P27: «сознательно
оставленный тёмный якорь»), тёмные секции Manifest/Footer (`bg-surface-accent`),
текст/бордеры `text-burgundy`/`border-burgundy` (не фоны).

**Проверки:** `npm test` 116/116 ✓ · `npm run lint` чисто ✓ · `npm run build` ✓ ·
grep `bg-burgundy|bg-burgundy-dark|bg-maroon` по src/+app/ — 0 вхождений ✓

**Ревью:** Codex (scripts/codex-run.ps1, MODE: review, песочница read-only), 2
раунда — в обоих `findings: none`. Отчёты: .agents/runs/maroon-bg-review/report-1.md,
report-2.md (артефакты локальные, в git не коммитятся).

**Контраст:** цвета не менялись — действуют результаты P28/P29 (cream на
burgundy ≈ 11.5:1, выше WCAG AA 4.5:1).

**Риски:** низкие; откат — revert одного коммита (3d12e12; до GitHub
rebase-merge — a0e9969). Визуальный эффект нулевой, верификация — кодом,
не скриншотами.

**Ссылки:** PR https://github.com/ageevcahtac-alt/xo-coffee/pull/1
